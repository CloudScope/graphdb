# Architecture decision records

DESIGN.md §13 holds the decisions made *at design time*, before implementation.
This directory is for decisions made **during** implementation — where a phase
hit something the design did not anticipate and the resolution is worth keeping.

One file per decision: `NNN-short-slug.md`, with context, the decision, the
alternatives rejected, and the consequences. If a decision here contradicts
DESIGN.md, say so explicitly and update DESIGN.md's decisions log to point here.
